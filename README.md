# Ocean Study Quest

勉強すると海の生き物が育ち、学習完了で手に入る「エサ」を使って魚釣りを楽しめる、スマートフォン中心の学習PWAです。

## 主な機能
- Today's Mission：追加・編集・削除・並べ替え・完了
- 学習タイマー：通常表示／Study Race表示
- 3D風海洋キャラクター10種
- 卵→あかちゃん→こども→わかもの→おとな＋レジェンドの育成
- XP・レベル・間違い直し真珠
- 魚釣りミニゲーム・魚図鑑・コイン
- 学習記録・7日グラフ・振り返り
- 保護者PIN、教材時間設定、効果音・読み上げ
- JSONバックアップ／復元
- A4 Today's Mission印刷
- PWA / Service Worker / オフラインキャッシュ

## GitHub Pages
このフォルダの中身をそのままリポジトリの `main` ブランチへ配置してください。公開起点は `index.html` です。

外部CDN・API・APIキーは使用していません。
